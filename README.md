# Villa Martins — Inhaca Island

A modern, mobile-first website concept for Villa Martins in Inhaca, Mozambique.

## Features

- Immersive one-page hospitality experience
- Responsive layouts for mobile, tablet and desktop
- Rooms, activities, gallery and transfer information
- Complete 27-photo property gallery with full-screen viewer
- Eight-language visitor experience: English, Portuguese, French, Afrikaans, Dutch/Nederlands, Danish, Scottish Gaelic and Mandarin Chinese
- Booking enquiry flow with WhatsApp and email hand-off
- Accessible navigation, dialogs, focus states and reduced-motion support

## Local preview

Open `index.html` directly or serve the directory with any static web server.

## Deployment

The site is deployed from the repository root with GitHub Pages.
